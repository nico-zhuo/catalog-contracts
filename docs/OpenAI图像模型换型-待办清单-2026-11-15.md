## 〇、两轮检查的核心新发现（改变决策的事实）

1. **gpt-image-1 上游已停服**：OpenAI API reference（developers.openai.com，2026-11-15 实拉）明确 "gpt-image-1 was shut down on October 23, 2026. Use gpt-image-2.5-sunburst or gpt-image-2.5-flare instead."。OpenRouter 页面仍挂列（残留），**不得新建档** → 用户原始 4 模型清单中此项出局。
2. **僵尸阈值不自动覆盖（P0 资损风险）**：arui `generation-queue.server.ts` 的 image 分支三条 11min 匹配规则（显式 Set / 池尾段 / flux 专属两后缀）对新 tierId 全 miss → 默认 3min；而 worker 对 OpenRouter 同步上游的 fetch 上限 480s > 3min → **先退款后出图**。必须在 `IMAGE_ASYNC_MODEL_IDS` 显式加行。
3. **-or 后缀无技术收益**：僵尸阈值三条匹配规则均非 `-or` 通配；klein（OpenRouter 无 Replicate 前身）先例不带 -or。gpt-image-2.6-flare 从未有过 Replicate 档 → **tierId 定 `gpt-image-2-6-flare`（不带 -or）**，与工具内 gpt-image-1-5 / gpt-image-2 / gpt-image-2-5-sunburst 兄弟档命名一致。
4. **归档表可直接复用**：gpt 系默认几何（1024/1536/1920/≈2240 长边）落入 flux 族归档分档（<1536→1K / 1536-2047→1.5K / ≥2048→2K）的分布与 flux 完全一致（1:1→1K、3:2/2:3/16:9/9:16→1.5K、21:9→2K、4:3/3:4→1K）→ 决策④维持归档时仅需白名单加精确枚举行，零结构性改动。
5. **perUnit(aspect_ratio) 以 quality 收 defaults 为前提**（backend 检查结论）：仓内 gpt 系先例全部 perUnit(quality)；quality 若暴露则成本随 quality×token 双浮动无法单维列表。且上游 `quality:"auto"` 按 high 档计费 → defaults 必须显式 `quality:"high"`，不许省略。
6. **flare 8 个具名比例与 flux-2 系完全同集**（1:1/4:3/3:4/3:2/2:3/16:9/9:16/21:9）→ 比例 labelKey 零新增；auto 按三先例不暴露（defaults 锁 1:1，非枚举回退 1:1）。

## 二、T-DEC 锚点简报（gpt-image-2.6-flare，quality=high）

锚点来源：fal.ai GPT Image 2.6 官方费率页（费率与 OpenRouter 实拉完全一致 $8/$30；估算表按 token grid 计算），并与 Medium 实测 token 数据交叉验证一致（1024² low 824 tok / medium 1449 / high 1758 ↔ 表中 $0.02469/$0.04347/$0.05268）。**所有值标 ≈，首笔真实账单回填校准（#11）**。

| aspect_ratio | 输出尺寸（默认几何） | 上游成本(high) | 积分 ceil(×300) 基线 | **建议表值（含文本 token 缓冲 +1）** | 归档档级 |
|---|---|---|---|---|---|
| 1:1 | 1024×1024（实测级锚点） | $0.05268 | 16 | **≈17** | 1K |
| 4:3 / 3:4 | 1024×768 / 768×1024 | $0.03612（768×1024 推定同价） | 11 | **≈12** | 1K |
| 3:2 / 2:3 | 1536×1024 / 1024×1536 | $0.04116（1536×1024 推定同价） | 13 | **≈14** | 1.5K |
| 16:9 / 9:16 | 1920×1072 / 1072×1920 | $0.03945（1072×1920 推定同价） | 12 | **≈13** | 1.5K |
| 21:9 | ≈2240×960（推定，16 倍数网格） | **无锚**（同面积 16:9 为 $0.03945，按 >16:9 推定） | — | **≈14** | 2K |

- 文本 prompt 边际：in_text $5/1M，300 token ≈ $0.0015（1:1 档约 0.9 积分）→ +1 缓冲覆盖典型长 prompt；基线值则超长 prompt 微亏。**两案供拍板，建议含缓冲案**。
- maxDimension：不暴露 size/resolution → 默认几何最大长边 = 21:9 ≈2240 → **md ≈2240（推定标 ≈）**。注意：同族 Replicate 档 md=3840 是其 resolution 可到 4K 的缘故，flare 不可照抄（backend 检查项③的 3840 建议据此修正为 2240）。
- handler 文件头注释按 #11 写证据链（本表 + fal/medium 来源 + 实拉日期）。
