## 4. 阶段 C · 定价页版式（B 案）

- 三卡：Free / Pro / Ultra，等高；移动端单列。
- 卡结构：名称 → tagline → 价格（月/年切换沿用）→ 副行（`Billed monthly · $12/mo billed yearly`）→ CTA（黑底白字）→ **卡内模型块**（`Upgrade to unlock all advanced models` + 2 行 × 5 彩色图标 + 品牌名）→ 权益行（✓/✗ + tooltip）。
- Free：10 credits/day · 1 concurrent · Standard queue · ✗ Commercial license
- Pro：2,000 credits/month · Up to 2,000 fast images · Up to 125 basic videos · 2 concurrent · Priority queue · Commercial license
- Ultra：5,000 credits/month · Up to 5,000 fast images · Up to 312 basic videos · 4 concurrent · Highest priority queue · Commercial license · Buy extra credits anytime
- 页面级：`No watermarks on any plan · Cancel anytime · Secure checkout by Stripe`
- 角标：Ultra 右上 **亮绿 Recommended**；当前档黑边 + `Current plan`。
- 颜色：去紫（`ring-primary`/`bg-primary` → 黑白/亮绿）；CTA hover 反色。
- tooltip 文案见 `docs/定价页Plan卡片改版-待办清单.md` §7.3（fast images / basic videos 按估算口径，不点名模型）。
- **不动**：价格、Stripe planId、JSON-LD、对比表、FAQ、一次性积分包、月/年切换逻辑。

## 5. 阶段 D · 高级模型门禁（同批）

### 5.1 服务端（权威）
`api.ai.submit.tsx`：
1. 把「用户订阅状态查询」前移到积分检查（`:455`）之前；
2. 解析 catalogEntry 后：`if (isPremiumTier(catalogEntry.tierId) && getEffectiveTier(user) === "free")` → `403 { code: "PREMIUM_PLAN_REQUIRED" }`，**不建 generation、不扣费**；
3. 错误码加入前端错误映射表（不裸显示英文）。

### 5.2 客户端（体验）
- `unified-prompt-bar.tsx:2312` 之前：`if (isPremiumTier(currentTier.tierId) && effectiveTier === "free") { onPremiumRequired?.(); return; }`
- 弹窗：`PremiumRequiredDialog`（新）→ 内部渲染 `<PlanCardList variant="modal" />` + `usePlanCheckout`；CTA 直接进 Stripe checkout；
- 画布页 `ai-canvas.$projectId.tsx:697`：加 `PREMIUM_PLAN_REQUIRED` → 同一个弹窗；
- 入口覆盖：bar 在 128 工具页 + 首页 + 聚合页，一处拦截全覆盖；画布 regenerate 走 BFF 错误分支。

### 5.3 文案 / i18n
- 新增 key（pricing + modal）：卡内块标题、10 个模型品牌名、4 条 tooltip、`Recommended`、`Billed monthly` 变体、弹窗标题/说明/CTA（预计 20–25 条），en 源 + 32 语。
- 弹窗文案草案：`Advanced models require Pro or Ultra` / `Upgrade to unlock every advanced model and keep your credits.` / CTA `Upgrade to Pro`、`Upgrade to Ultra`。

### 5.4 边界
- Free 仍可用 8 个非 premium 档（flux-schnell / seedance-1-pro-fast / seedance-1-5-pro / recraft-remove-background / bria-remove-background / qwen3-tts / inworld-tts-2 / inworld-1.5-mini）；
- **59/128 工具没有任何非 premium 档** → Free 用户在这些工具上完全不能生成（用户已定：不处理，后续补免费档模型）；
- 取消/欠费/过期 = free（`getEffectiveTier`）；
- 已保存画布的 premium 档 regenerate → 同样拦截。
