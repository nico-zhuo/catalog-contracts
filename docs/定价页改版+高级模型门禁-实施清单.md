## 4. 阶段 C · 定价页版式（B 案）

## 5. 阶段 D · 高级模型门禁（同批）

### 5.1 服务端（权威）
`api.ai.submit.tsx`：
1. 把「用户订阅状态查询」前移到积分检查（`:455`）之前；
2. 解析 catalogEntry 后：`if (isPremiumTier(catalogEntry.tierId) && getEffectiveTier(user) === "free")` → `403 { code: "PREMIUM_PLAN_REQUIRED" }`，**不建 generation、不扣费**；
3. 错误码加入前端错误映射表（不裸显示英文）。

### 5.2 客户端（体验）
- `unified-prompt-bar.tsx:2312` 之前：`if (isPremiumTier(currentTier.tierId) && effectiveTier === "free") { onPremiumRequired?.(); return; }`
- 弹窗：`PremiumRequiredDialog`（新）→ 内部渲染 `<PlanCardList variant="modal" />` + `usePlanCheckout`；CTA 直接进 Stripe checkout；
- 画布页 `ai-canvas.$projectId.tsx:697`：加 `PREMIUM_PLAN_REQUIRED` → 同一个弹窗；
- 入口覆盖：bar 在 128 工具页 + 首页 + 聚合页，一处拦截全覆盖；画布 regenerate 走 BFF 错误分支。

### 5.3 弹窗结构
- 只用 `PlanCardList variant="modal"` 渲染 **Pro / Ultra 两卡**（不放 Free），横排两列；窄屏单列可滚动；
- 主题跟随主站（`bg-popover`/`text-foreground`），图标底板白色圆角（深色主题下也清晰）。

### 5.4 文案 / i18n
- 新增 key（pricing + modal）：卡内块标题、10 个模型品牌名、4 条 tooltip、`Recommended`、`Billed monthly` 变体、弹窗标题/说明/CTA（预计 20–25 条），en 源 + 32 语。
- 弹窗文案草案：`Advanced models require Pro or Ultra` / `Upgrade to unlock every advanced model and keep your credits.` / CTA `Upgrade to Pro`、`Upgrade to Ultra`。

### 5.5 边界
