## 0. 检查结论（Lead）

1. 现状：`search-index.ts` 结果含 `tools + categories` 两组，空输入展示分类；排序按「匹配分数 → nav 顺序」。`header-search.tsx` 渲染 Tools/Categories 两段。
2. 仓库内**没有现成的热度数据**：`nav-config`/`canvas-tools` 仅产品顺序；`pricing.popular` 是套餐标记，无关。
3. 真实热度可算：Supabase `generations` 表有 `tool_slug`（= canvas tool slug，如 `ai-text-to-image`）+ `status`（`COMPLETED`）+ `created_at`。
   → 新增 BFF 聚合接口：统计近 30 天 `COMPLETED` 的 `tool_slug` 次数，返回按热度排序的 **route href** 列表。
4. `generations.tool_slug` 是 toolSlug，搜索索引是 route href，需要映射：已生成 **128 条 `TOOL_SLUG_TO_HREF`**（自动扫描各 route 的 `TOOL_CONFIG_SLUG`，文件 `/tmp/tool-slug-href-map.ts`，可直接并入仓库）。
5. 无分类展示后，查询命中分类的逻辑要移除；空输入改为「热门工具 Top N」（text-to-image 首位）。
