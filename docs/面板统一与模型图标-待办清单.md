### 0.2 面板现状（text-to-image 为什么"好看"）

`text-to-image` 是唯一试点：`unified-prompt-bar.tsx:849` `isParamSettingsPilot = slug === "ai-text-to-image"` → 走
`ParamSettingsChip`（参数收进状态胶囊 + 上拉面板）+ 工具栏右侧 **Generate 胶囊（积分并入）**；
其余 131 个工具走旧 `ParamForm`（内联参数）+ 独立积分 + absolute 圆钮发送。

| 差异点 | pilot（text-to-image） | 其余 131 | 位置 |
|---|---|---|---|
| 参数区 | ParamSettingsChip | ParamForm | `unified-prompt-bar.tsx:849 / :3156-3173` |
| 右组 | Generate 胶囊 + 积分并入 | 独立积分 + absolute 圆钮 | `:3197-3211 / :3214-3237 / :3242-3257` |
| 模型选择 | 富面板 `ModelPickerPanel`（103 工具） | 朴素 `CanvasDropdown`（29 工具） | 门控 `:3113` |
| 文本输入 | textarea（122 工具） | 10 工具无 textarea，降级占位 `<p>` | `:2961-2986 / :2988-3046` |
| 上传槽 | 图片 100 / 音频 4 / 视频 4 | 同左（槽位与参数区分开渲染） | `:2818-2959` |
| 移动端 | 无独立 DOM，组件 + CSS 自适应；两面板均 Portal | 同左 | `isDesktop` 只用于回车发送 `:622/:2995` |

**不能无脑 switch 的证据**：
1. `ParamSettingsChip` 只渲染 `enum` + `boolean`；`text/number` 归入 `otherFields` 但兜底只 `.filter(enum)`（`param-settings.tsx:86-96 / :369-394`）→ **9 个工具会丢控件**（text 5 / number 3 / 1 个致命）。
2. **致命个案**：`ai-singing-generator` 的 `minimax-music-cover` 档 `prompt` 为 required 非主文本，切 pilot 后被隐藏 → `requiredRenderedTextParams` 永远为空 → **该档永久不可提交**（`:892-898 / :2784-2792`）。
3. **8 个工具胶囊无摘要**（无 `aspect_ratio/image_size/quality/num_images/resolution` 任一分组）→ 胶囊只剩箭头。
4. **submit 透传是硬编码白名单**（`:2420-2620`，pilot 仅出现在 `:2503/:2506/:2512/:2524` 四条）→ 渲染切换不改透传，但新参数若不在名单会"改得动、传不出"（踩坑 #41 同族）。
5. 后端补充：**108/110 工具「同工具不同档 params 集合不同」**（能力子集，正常）→ 面板必须按当前所选档渲染；**363 个 enum 只有 1 个选项**（resolution 351 为 display-only、aspect_ratio 12）→ 必须保留"单选项也显示"例外（踩坑 #43 同族）；4 个工具 `params=[]`（background-remover / transparent-background / depth-map-standard / texture）。

**工作量分流**：
- **119 个工具** 只需改 `:849` 单 slug → `Set`（gate-only，低风险）；
- **13 个工具** 必须同时改 `ParamSettingsChip`（drop 9 ∪ blank 8，交集 4：character-voice / rapper / singing / tts）。

### 0.3 图标现状（用户反馈"有些模型没有图标"）

| 项 | 结论 |
|---|---|
| branding 表 | `app/config/model-branding.ts`：显式 42 条 + `REPLICATE_TIER_TAILS_BY_TOOL` per-tool 展开 → 覆盖 **1575 个 clientModelId / 103 个 toolSlug**（全部 image 家族） |
| 可见档覆盖 | 1575 / 1774 = **88.8%**；partial = **0**（不存在"部分档缺 icon"的混组） |
| 整表缺失 | **29 工具 / 199 档** → 门控 `:3113` 为 false → 整体退化朴素下拉（无图标/无分组/无积分徽标） |
| 资产 | `public/brand/` 仅 5 个 SVG（flux/google/openai/seedream/xai）；branding 引用与磁盘 **1:1，0 缺 0 多** |
| 根因 | 与踩坑 #7 完全同型：audio/video/3D 的 branding 条目 = 0 → 不是"某张图丢了"，是"整张表没配" |

**29 工具明细（按家族）**：
- video 16 工具 / 150 档：10 个 ×14 档池工具（text-to-video、text-to-animation、script-to-video、cartoon-video-generator、image-to-video、logo-video-maker、video-ad-maker、video-intro-generator、video-script-generator、anime-video-generator）+ video-to-video(1) + video-enhancer(2) + video-upscaler(2) + audio-to-video(3) + video-background-removal(1) + lyric-video-maker(1)

- 3D 3 工具 / 6 档：image-to-3d-model 2、text-to-3d-model 2、3d-character-generator 2（client 前缀不规则 `arui-3d-img/text/character-*`）
- image 4 工具 / 12 档：background-remover 5、transparent-background 3、depth-map-generator 2、texture-generator 2

**可执行范围**：排除 4 个产品命名/停做遗留工具后 = **25 工具 / 191 档 / 15 个新增 vendor SVG**。
最小方案只挂 `icon + vendor + eta` → **32 语言 0 新增**；若补 `descriptionKey/vendorSubtitleKey` ≈ 45×32 + 15×32 ≈ 1920 leaf，建议后置单独文案批。
