| 尺寸 | 建议 `text-[10px] leading-4 italic font-bold tracking-wide uppercase rounded-full px-1.5`（比现网 `Badge` 的 `text-xs/px-2` 小一号） |

**布局风险（实测估算）**：面板 `w-[min(34rem, calc(100vw-2rem))]`（`model-picker-panel.tsx:321`）。桌面 544px 够；**375px 视口 = 343px** 时，`ByteDance Video Upscaler 1080p`（30 字符 ≈245px）+ 徽标 ≈64px + 图标/间距/内边距 ≈62px ≈ 371px **会溢出**。名称行没有 `min-w-0`，溢出会顶出横向滚动 → 必须处理（名称 `truncate` 或徽标换行/缩小）。

## 3. 数据表设计（推荐）

新增 `app/config/model-premium.ts`（纯新增文件，不动 `model-branding.ts`）：

```ts
/** 非高级（不打 PREMIUM）的 tierId —— 用户 2026-11-09 指定 8 个；其余一律高级 */
export const NON_PREMIUM_TIER_IDS: ReadonlySet<string> = new Set([
  "flux-schnell", "recraft-remove-background", "bria-remove-background",
  "qwen3-tts", "inworld-realtime-tts-2", "inworld-realtime-tts-1-5-mini",
  "seedance-1-pro-fast", "seedance-1-5-pro",
]);
export function isPremiumTier(tierId: string): boolean { return !NON_PREMIUM_TIER_IDS.has(tierId); }
```

- **为什么按 `tierId`**：`CatalogTierClient` 直接带 `tierId`（`use-catalog-tiers.ts:16-40`）；同尾段跨工具同值 ⇒ 62 行覆盖 1766 实例。按 clientModelId 要 1766 行；按 per-tool 白名单展开会踩踩坑 #46。
- **为什么"默认高级"**：严格照你的口径（除名单外都高级）；代价是**新模型上线自动变 premium**（守卫要打印新增 tierId 提示）。
- **备选**：显式 54 条 premium 白名单（新模型默认非高级，更保守，但与你的口径相反）。→ §5-4 决策。
